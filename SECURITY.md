# Security Policy

## Supported scope

The current experimental release is OIX v0.1. Security fixes will be developed on the default branch. There is no service-level agreement or guaranteed response time.

## Report a vulnerability

Please do not publish exploitable details, credentials, private keys, or sensitive personal data in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled. Otherwise contact the repository maintainers privately through a verified channel listed on the GitHub profile.

Include:
- affected version and commit
- impact and realistic attack prerequisites
- minimal reproduction steps or a safe proof of concept
- suggested mitigation, if known

Do not test against systems you do not own or have explicit permission to assess.

## Security claims

OIX is experimental and has not undergone a formal independent audit or certification. Ed25519 signatures, hashes, and tests are controls, not a guarantee of security. Do not describe this project as certified, military-grade, or production-hardened.
